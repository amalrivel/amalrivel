## About me

I'm an Indonesian **Software Developer based in Japan**, interested in building practical software from interface to data and product flow.

I like starting from a real problem, understanding how people would actually use the product, and then building the application end to end. My current work is centered around **TypeScript, modern React tooling, reusable UI systems, and relational data**.

Currently, most of my time goes into building and refining **Genshu**, while continuing to experiment with product ideas through projects like **Finori**.
